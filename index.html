Case-file preferred explanation

The supplied case file favours option C: Elena moved the HSM into emergency offline containment after a zero-day exploit; the attack path was enabled by Marcus’s compromised maintenance tap; and Kaelen altered logs or badge data in a way that framed Thorne.

The case file reports 89.2% confidence. This is not independently verified. Available evidence is circumstantial about who physically carried the HSM.

Key caveats

Do not treat altered CCTV, anonymous tips, or low-reliability alerts as definitive proof. Separate device or account attribution from proof of a person’s actions.
